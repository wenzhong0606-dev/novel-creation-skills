# 通用小说创作 Skill 体系

本仓库是跨小说项目复用的创作方法与 Skill 的**权威来源**。

## 建设目标

将经过整理、验证的小说创作方法封装为可复用、可组合、可持续演进的能力模块，供不同小说项目按需引用。

## 架构基线

- 总控层：识别任务、管理工作流、调度与协调 Skill。
- 创作工作流层：承担创意开发、故事架构、人物设计、情绪架构、章节设计、正文创作、修订和评审等工作。
- 专项能力层：承担因果链、伏笔回收、连续性、人物一致性、独立评审等可复用任务。
- 横向扩展：小说类型扩展包为多个工作流和专项能力提供类型约束，不构成第四层。

人物体系设计与情绪架构设计是两个独立的创作工作流 Skill，通过明确接口协同、迭代。

## 仓库治理原则

1. 本仓库维护通用方法、Skill、模板、评测和治理规范。
2. 单部小说的正文、世界观、人物设定、项目决策和进度资料留在该小说自己的项目仓库。
3. 小说项目通过项目级 Skill 清单声明使用的 Skill 及版本。
4. GitHub 中的版本是通用 Skill 的权威版本；项目应明确锁定所使用的版本。
5. 不将单一小说中的有效做法未经跨项目验证直接标记为通用成熟能力。

## 当前状态

当前处于架构与治理基础建设阶段。架构已建立初始基线，具体 Skill 将按实际需要逐步开发和验证；本仓库不以 Skill 数量作为成熟度指标。
